# v1.154.518 (2026-08-05)

feat(#1447): merge attached digital objects into the image carousel (option c). Objects attached directly to a description now render as tiles in the same imageflow strip as the child thumbnails, instead of a separate grid. New _attached-carousel-tiles partial (image-linked tiles, matching the child-tile style) injected into each strip's flex container: the shared _digital-object-viewer (archival/DAM/museum), gallery/show, and a standalone strip on library/show (which has no native carousel). The strip guard now also fires when a record has attachments but no children, so an attachment-only record still shows the carousel. Display is for everyone via the carousel; _attached-objects is now the EDITOR-ONLY management panel (attach form + per-item remove) - non-editors no longer see the redundant grid. Verified: attachment-only record shows the strip with the tile (target=_blank to the reference image); management panel renders 0 bytes for guests. Child + attachment mix share one strip.
