# v1.154.705 (2026-09-01)

fix(archaeology): surface the new relationship interchange in the UI - the v1.154.704 routes had no link anywhere. Export relationships CSV and Import relationships CSV are now buttons on the Stratigraphic Consistency page beside Export GraphViz DOT, Export Data Package and Import LST, which is where an excavator already goes to work on the matrix. Found while capturing screenshots for the Harris Matrix user manual: the report page rendered three action buttons and neither new endpoint was reachable by clicking, so the feature shipped complete and invisible. Also adds tests/e2e/docs-harris-matrix-screenshots.spec.js, the Playwright capture used to produce the manual figures - it asserts the login actually took before shooting, because the first run silently screenshotted the login page nine times and still reported a pass.
