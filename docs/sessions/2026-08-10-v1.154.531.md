# v1.154.531 (2026-08-10)

refactor(translation): harmonize the machine-translation target-language pickers onto AhgCore\Support\LanguageOptions::translationTargets(). The MT target list was copy-pasted with drifting subsets and label styles (siSwati vs SiSwati, Kiswahili vs Swahili, Sepedi vs 'Sepedi (Northern Sotho)') across TranslationController::TARGET_LANGUAGES and four pickers (_translate-modal, _translate-sbs, _translate-cco-values, information-object show). All now delegate to one canonical 21-language superset (11 SA official + nd/sn SADC + international) so every picker offers the same options with consistent labels - superset chosen so no picker loses a previously-offered language; adds nd/sn/it where missing. Controller const -> private static targetLanguages() delegator (2 refs updated). Verified: canonical set = 21 with zu/xh/nr/nd/sn/it present, controller method resolves, view:cache compiles clean. DELIBERATELY EXCLUDED: MultilingualRecordService::LANGUAGE_LABELS - a broader endonym display-resolver (Francais, Nederlands, Chinese, Japanese) mirroring the UI-locale switcher, a different concern.
