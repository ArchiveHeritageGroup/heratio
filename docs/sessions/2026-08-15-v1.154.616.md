# v1.154.616 (2026-08-15)

fix(doi): ahg:doi-mint no-ops cleanly on an instance with no DOI configuration. With the atom-connection blocker removed in v1.154.615 the command finally ran on sasa and reported the honest next condition - every candidate failing with 'no active ahg_doi_config row' - which is a configuration choice, not a runtime fault, and would have failed the scheduled run for ever on any instance not minting DOIs. It now checks for an active config once, says what is missing, and exits 0
