# v1.154.522 (2026-08-05)

fix(errorlog): stop PsySH/tinker REPL errors polluting the operator error log. The global exceptions->report() in bootstrap/app.php logs every Throwable to ahg_error_log, but an interactive 'artisan tinker' session runs in the console where request() falls back to a synthetic GET <app.url> web context (user_agent=Symfony, ip=127.0.0.1) - so a parse error from a pasted tinker snippet was recorded as a bogus 500 GET on /admin/errorLog (the T_NS_SEPARATOR line-9 report). Now skips any exception whose class starts with Psy backslash; real web + queue-job errors are unaffected. Also cleared the 2 stale dev rows (the tinker Psy entry + the already-fixed print-label 1062 UniqueConstraintViolation from Aug-4).
