# v1.154.514 (2026-08-05)

chore(export): remove the 'EAD 4' export - it is not a published standard. EAD4 does not exist as an SAA release (current is EAD3, 2015); Ead4Serializer advertised a fabricated namespace (https://archivists.org/ns/ead/v4) + schema (ead4.xsd) that does not resolve, so the export misrepresented conformance to a non-existent standard. Pulled every user-facing path: the informationobject.export.ead4 route + ExportController::ead4(), the 'EAD 4 XML' menu links (_right-blocks, _record-sidebar-extras, library/show), the metadata-export format-list entry + the reports 'EAD 4 (Draft)' link. Ead4Serializer.php kept dormant so a real future EAD4 - or an honestly-relabelled RiC-harmonised extension - can re-enable it. EAD3 export unaffected. Views compile; export.ead4 route gone; no live ead4 references remain
