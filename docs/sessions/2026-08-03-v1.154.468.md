# v1.154.468 (2026-08-03)

fix(museum): serve museum-sector collection/series nodes (they had no viewable page). MuseumService::getBySlug inner-joined museum_metadata, which 404'd collection nodes (no CCO object metadata) - so a museum collection 302'd from the archival show to /museum/ and then 404'd. museum_metadata is now a LEFT join, and museum-ness is 'has museum_metadata OR has a museum display_object_config' (the two markers don't fully overlap: 63 metadata records vs 33 configs, only 31 shared), so every existing museum object still resolves, collections now render (with the descendant-image carousel), and non-museum records still 404
