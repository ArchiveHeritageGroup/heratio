# v1.154.568 (2026-08-11)

feat(spectrum): #1460 Phase 2 - Valuation to GRAP Heritage Assets bridge. Editing a Spectrum valuation (procedure PATCH) or the explicit 'Sync to Heritage Assets' button pushes the object's latest valuation into its GRAP heritage_asset (last_valuation date/amount, valuation_method, valuer, report reference, revaluation surplus + carrying amount) + logs a heritage_asset_valuation row. Fully gated: no-op when ahg-heritage-manage absent (Schema::hasTable guards, no cross-package class dependency); auto-sync updates an existing asset only, the button creates one if missing. ValuationHeritageBridge + ValuationBridgeController + acl route + gated button
