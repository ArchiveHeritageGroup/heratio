# v1.154.780 (2026-09-22)

fix(deploy): demo reset waits for detached artisan processes before restoring (CH-000175). A runInBackground scheduler event (ahg:optimize-models, hourly, so 00:00 UTC) and its schedule:finish outlive the scheduler lock; one booted mid-restore, the audit-trail provider re-created the ahg_audit_log triggers, and the dump's CREATE TRIGGER failed with ERROR 1359. Aborts after 600s rather than restore under a running process.
