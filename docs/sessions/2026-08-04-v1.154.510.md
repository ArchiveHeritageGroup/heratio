# v1.154.510 (2026-08-04)

feat(#1427): enforce graded ICIP access on the staff show page via a shared IcipAccessService. Extracted the ICIP cultural-access decision out of IcipController::checkAccess into a single shared AhgIcip\Services\IcipAccessService (checkAccess now delegates - one source of truth, no duplication). Wired it into InformationObjectController::show(): the record show page now honours community cultural protocols for authenticated staff, not just public/machine surfaces (DisclosureGate). The check runs for every viewer so access to a restricted record is audited (icip_access_log) including custodians; only the 403 block is bypassed for editors (anyone with 'update' on the record - admins via AclService admin bypass) and, inside the check, a steward of the restricting community. Everyone else fails closed on an unsatisfied restriction; workflow-state protocols (elder_approval/under_consultation) stay non-blocking. Unrestricted records return early with no log write, keeping the common path cheap. Verified: anon + read-only staff -> 403; editor/admin -> allowed(bypass); all views audited; fail-closed on initiated_only/gender/custom; steward-grant + workflow-consultation paths correct
