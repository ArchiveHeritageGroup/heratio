# v1.154.478 (2026-08-03)

fix(icip): honour the time window on ICIP restrictions. #1426 - DisclosureGate::icipRestrictedIds() collected every icip_access_restriction row regardless of start_date/end_date, so a mourning-period/seasonal suppression with an end date stayed permanent on every machine surface (OAI/REST/GraphQL/SPARQL/portable export) and a future-dated one applied immediately; now filters to the active [start_date,end_date] window on both the direct and descendant-subtree queries, matching the interactive path. #1427 - checkAccess() also enforces the date-driven seasonal + mourning_period types (getObjectRestrictions already window-filters them, so they auto-lift); attribute-based (gender/custom) + workflow (elder/consultation) types remain deferred to the user-attribute model, documented in code
