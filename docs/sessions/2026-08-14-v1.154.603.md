# v1.154.603 (2026-08-14)

fix(federation): a disabled federation is a choice, not a failure. ahg:federation-harvest returned FAILURE when federation_enabled=0, so every instance that simply does not federate logged a failed scheduled command on every run. It now says so plainly - an operator running it by hand still sees why nothing happened - and exits 0, matching the same correction already applied to ahg:triposr-health and ahg:ai-condition-status. Non-zero stays reserved for a harvest that was attempted and went wrong
