# v1.154.674 (2026-08-25)

chore(bootstrap): guard the archaeology provider so an instance can opt out - sasa. ahg-archaeology is one of the few packages wired by hand rather than by Laravel auto-discovery: root composer.json carries its PSR-4 entry and bootstrap/providers.php named the provider UNGUARDED, so removing the autoload line to switch the module off took the whole app down on boot instead. It is now wrapped in class_exists() exactly as ahg-harris-matrix has been since v1.154.653, which makes that per-instance composer.json line the switch. Where the entry is present - heratio-dev, heratio - this registers exactly as before and nothing changes: verified 30 archaeology routes still resolve on dev, provider still class_exists, 231 Feature tests pass. The point is sasa, a GLAM archive with all four archaeology tables empty, zero linked descriptions, no reference to AhgArchaeology from any other package and no archaeology route named anywhere outside the module - 26 routes of excavation-recording surface it has never had a use for. Tables are left in place and NOT dropped: they are empty and harmless, and dropping them is irreversible for no gain.
