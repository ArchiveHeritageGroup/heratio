# v1.155.0 (2026-09-28)

feat(storage): hierarchical storage locations on a closure table (heratio#1514, atom-ahg-plugins#193 option 2). Port of the AtoM storageLocation module on the same ahg_storage_location tables: browse with tree and search, show with path and contents, create/edit with a subtree-safe parent picker, delete refused while children exist, JSON locations/tree/search. parent_id is the source of truth; ahg_storage_location_closure is maintained by the shared ClosureMaintenanceService in the same transaction and rebuildable with ahg:build-closure --table=ahg_storage_location. Types and capacity units come from the Dropdown Manager. Staff-only reads, acl writes, admin delete. StorageLocationTest asserts the closure equals a rebuild after every create, move and delete. Also carries the CH-000175 php-fpm reload in heratio-demo-reset.sh.
