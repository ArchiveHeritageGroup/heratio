# v1.154.533 (2026-08-10)

fix(gallery): #1458 - Artwork Template selector no longer snaps back to Painting. The template pills submitted the form with a switch_template flag to 'reload with the new template', but no server code reads switch_template and no fields are template-conditional, so the reload did nothing except re-render with the hardcoded-active Painting pill (and could wipe half-entered input on validation). Made the switch purely client-side: toggle the active pill + set the hidden template field in place, no round-trip; and drive the active pill from old('template', artwork->template ?? 'painting') so any save-validation reload shows the right one. Blade-only change; view:cache compiles.
