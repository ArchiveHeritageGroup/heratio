# v1.154.505 (2026-08-04)

feat(condition): #1452/#1453 - unify condition photos into one rich store (Option A). Both condition systems - the io-manage Condition Report and the Spectrum Condition Check - now share the rich spectrum_condition_photo table via a polymorphic source link (source_type report|check, source_id). Migration adds source_type/source_id, makes condition_check_id nullable (report photos have none), backfills the existing check photos, and migrates the 7 thin condition_image rows in as report-sourced (idempotent, non-destructive). ConditionController show/uploadPhoto/deletePhoto now read/write the unified store (photo_type aliased to image_type so the report view is unchanged); the standalone admin/spectrum/condition-photos page redirects to the condition-namespace photo manager (io.condition.spectrum.show) on the same store. Core schema mirrored (columns + idx_scp_source). Verified: 16 check + 7 report photos in the unified store, report show renders them, migration idempotent. Per-instance deploy: php artisan migrate --force.
