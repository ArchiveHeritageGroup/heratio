# v1.154.702 (2026-08-31)

feat(exhibition): print case labels for an exhibition's objects in one click. The batch label printer already accepted a list of slugs and, since the local QR work, renders a scannable code per label - but a curator had to reselect every object by hand to use it for an exhibition, which is the one place a set of labels is most obviously wanted. The exhibition objects page now offers 'Print object labels with QR', posting the slugs of the objects actually placed in that exhibition straight to the batch printer, capped at the printer's own limit of 100 and showing the count so it is clear what will be produced before printing. It renders only when the exhibition has objects AND the label route exists, so an instance without the label package sees nothing rather than a broken link. Verified by driving it in a browser: the button appears on both demo exhibitions, clicking it opens the batch printer, and the sheet comes back as an Avery L7159 template carrying the object title, its object number and one locally-rendered QR - with zero external requests, which is the point of the whole exercise. 246 Feature tests pass.
