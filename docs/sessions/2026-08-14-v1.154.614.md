# v1.154.614 (2026-08-14)

fix(3d): stop the sudo alert-mail flood from thumbnail generation. generate-thumbnail.sh probed 'sudo -n $BLENDER --version' BEFORE trying Blender directly. sudo's -n stops it prompting but a denial is still logged and MAILED to root, so on a host where the apt build runs perfectly well as www-data every thumbnail produced a 'a password is required' security alert - and with ahg:3d-derivatives on a two-minute schedule that is a mail flood, for a privilege escalation that was never needed. The order is now direct-first, with sudo kept only as the fallback for its original reason (snap Blender cannot run as www-data because of the snap home-directory restriction). Worth noting the sudoers rule on this host grants /snap/bin/blender while snap Blender is not installed and the binary in use is /usr/bin/blender, so that rule could never have matched - the sudo branch was pure cost. Verified: prod regenerates derivatives (success=1 failed=0) with zero new sudo denials. This surfaced only because v1.154.613 fixed the doubled uploads path, so the command finally got past the missing-file check and reached the Blender step
