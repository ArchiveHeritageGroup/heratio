# v1.156.4 (2026-09-28)

docs(reference): session note for 22-28 September - the demo reset, the audit trail, the storage movement log (CH-000175, CH-000139, CH-000177, heratio#1514, heratio#1515). Records
  the root cause that took three attempts to find: maintenance mode leaks for up to two minutes after artisan down because php-fpm caches stat() for realpath_cache_ttl, so leaked web requests boot the app and its providers create schema mid-restore - a
  host-wide fact that applies to any deploy or restore, not just this script. Also records why two of the four lost nights went to the baseline version stamp rather than the bug, that AuditService never autoloaded so three callers' events were never
  audited, that dev and prod share one inference signing keypair whose dev copy was world-readable for three months, and that boot-time schema mutation is the class behind the 1359 and 1050 collisions.
