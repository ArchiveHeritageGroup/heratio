# v1.154.569 (2026-08-11)

feat(spectrum): #1460 Phase 2 Loans->ahg-loan bridge + fix(branding): rename remaining 'Museum flow' label to 'Collections Procedure'. Loan bridge: editing a Spectrum loan_in/loan_out (PATCH) or the 'Create/sync loan record' button creates/updates the rich ahg_loan (loan_type in/out, partner, dates, purpose, title, notes) and links the object via ahg_loan_object. Fully gated: no-op when ahg-loan absent (Schema::hasTable guards, no cross-package dependency); auto-sync updates an existing loan only (matched by loan_number, idempotent), button creates. Branding: the object show-page 'Museum flow' button (dam/museum/library/io-manage) -> 'Collections Procedure' (lowercase variant missed in v1.154.566); ahg_footer_standards entry updated in-DB
