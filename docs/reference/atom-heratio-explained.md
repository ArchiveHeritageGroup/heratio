AHG Extensions for AtoM are the AHG plugins that extend an Access to Memory (AtoM) installation, running on Symfony 1.4. They are not Heratio. "Heratio" always means the standalone Laravel GLAM application, which shares only AtoM's database structure so that an AtoM site can switch to it in place. The older label "AtoM Heratio" for the AtoM plugins is retired and should not be used. The official documentation for Heratio is at [https://heratio.theahg.co.za/help](https://heratio.theahg.co.za/help). AHG Extensions for AtoM are AtoM with AHG plugins; Heratio is pure Laravel.
