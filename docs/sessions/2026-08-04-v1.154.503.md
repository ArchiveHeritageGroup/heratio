# v1.154.503 (2026-08-04)

fix(condition): #1453 - guide condition photo capture on create + swap Save/Cancel. The condition/create form intentionally has no photo upload (photos attach to a saved report via the io.condition.photo.upload endpoint on the report show page), which read as 'no photo option'. Added an info hint - 'Save the report first, then add condition photos (with damage annotations) on the saved report page' - and swapped Cancel/Save order for consistency. Architectural note on #1452/#1453: Heratio has TWO parallel condition-photo stores - condition_image (the report's own photos, shown+uploadable on condition/report/{id}) and spectrum_condition_photo (the separate admin/spectrum/condition-photos page); unifying them + full field parity with PSIS is feature-scale, tracked on those issues.
