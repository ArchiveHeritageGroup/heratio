# v1.154.488 (2026-08-03)

feat(archaeology): #1428 Phase 4b - context recording sheet PDF export. ArchaeologyController::contextPdf() renders a self-contained print view (context-sheet-pdf.blade: inline CSS, DejaVu Sans, AHG-green section headers, no external assets so dompdf needs no remote fetch) through the repo's standard new Dompdf\\Dompdf(isRemoteEnabled=false, html5, DejaVu Sans) loadHtml/setPaper A4 portrait/render/output, guarded by class_exists(Dompdf) with a styled-HTML fallback when dompdf is absent (CI-safe). The sheet carries the full context (type/phase/top+bottom elevation/excavation ref/excavator/dates/description/interpretation), the stratigraphic relationships grouped in REL_TYPES order, and a finds table. Route GET /context/{id}/pdf; a 'PDF sheet' button on the context view. Verified: valid %PDF-1.7, correct filename + application/pdf. No schema change.
