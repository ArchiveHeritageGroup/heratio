# v1.154.439 (2026-07-27)

v1.154.439: fix(#1425): hotfix two errors from the demo error log.

(1) [1520 hits] 'Too few arguments to function RicViewModeService::isRic(), 1 passed' - a regression from v1.154.438: the _ric-panel / _ric-entities-panel guards called isRic((int)$id) with ONE argument, but isRic(entityType, entityId) takes TWO (the composite key from v1.154.423). On show-ric it was masked by alwaysShow short-circuiting the ||, but the base ISAD show includes _ric-panel WITHOUT alwaysShow, so every ISAD record page fatalled. Both guards now pass isRic('information_object', (int)$id).

(2) [12 hits] 'syntax error, unexpected integer 1' in ahg-repository-manage/_upload-limit - a nested {{ __('1 GB = 1 000 000 000 bytes') }} INSIDE a {!! __(...) !!} argument (two places) compiled to invalid PHP (a nested echo inside the outer string). Pre-built the <abbr> GB markup in the @php block ($gbAbbr) and passed it as a :gb placeholder instead of nesting Blade.

Verified: base ISAD show page renders HTTP 200 with no 'Too few arguments'; isRic('information_object', id) works; the compiled _upload-limit passes php -l.
