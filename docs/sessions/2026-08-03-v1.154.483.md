# v1.154.483 (2026-08-03)

feat(icip): #1409 - OCAP governance event log. Every cultural-protocol change records an append-only ocap_event: TermProtocolService set/clear (term-level) and setObject/clearObjectProtocol (object-level) call OcapService::recordEvent (guarded by class_exists so ahg-core stays independent of ahg-icip; fail-silent so logging never breaks the write). Captures event_type, entity, label family/code, access_condition, actor and detail. Table auto-created via the provider governance-tables boot (idempotent, like icip_label_assignment_log). The OCAP dashboard gains a Governance events panel. External Local Contexts Hub API remains deferred (needs Hub credentials)
