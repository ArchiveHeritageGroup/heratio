# v1.154.552 (2026-08-10)

refactor(api): extract the self-documenting cockpit controller scaffolding into AhgApi\Concerns\ServesApiDocument. Cookbook/Maturity/Protocol controllers shared byte-identical options(), index() (JSON/HTML content negotiation), base(), wantsHtml(), withCors(), surfacesById() and the route resolver (resolve() in Maturity/Protocol, resolveRoute() in Cookbook - same body). All moved to one trait the 3 controllers now 'use'; each keeps only its own document() (JSON body) + html() (human page) that index() calls, plus its unique surfaces. resolveRoute() is a resolve() alias so Cookbook's call sites are unchanged. This is the base-controller dedup from the audit tail. Verified on dev: all 3 /open-data/{cookbook,maturity,protocol} return JSON:200 + HTML:200 with valid documents; lint clean.
