# v1.154.770 (2026-09-18)

fix(ric): RiC to Fuseki writes have never succeeded - Turtle @prefix directives were wrapped inside INSERT DATA, which SPARQL forbids, so Fuseki returned 400 on every attempt; splitPrefixes() moves to SparqlUpdateService and new buildInsertUpdate() hoists them into a PREFIX prologue as the single place the INSERT DATA/GRAPH wrapping is built. The queued fallback was equally dead: FusekiSyncService imported Illuminate\Support\Facades\Dispatch, which does not exist, so every enqueue threw Class not found, was swallowed by the surrounding catch, and fell through to the synchronous path - now Bus::dispatch. That fall-through also masked a third defect, FusekiSyncService building its own update string with the braces around the GRAPH body missing entirely; it now calls buildInsertUpdate() so the construction exists once rather than being repaired twice. CrmGraphSyncService's private duplicate of splitPrefixes is removed. New SparqlInsertWrappingTest covers the hoist, the braces, verbatim triples and prefix-free pass-through; ahg-ric suite 88/88.
