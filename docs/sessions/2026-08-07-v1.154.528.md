# v1.154.528 (2026-08-07)

fix(repository): #1528 - Language(s)/Script(s) on the repository add/edit form are now ISO pick-lists that actually save. The two ISDIAH description-control fields (desc_language/desc_script) were plain text inputs with no lookup AND were absent from the controller whitelist + repository_i18n, so any typed value was silently dropped. Convert both to <select> dropdowns (same ISO-639 language / ISO-15924 script sets as the archival description form), add desc_language/desc_script varchar(255) to repository_i18n (mirrored into core schema + idempotent Schema::hasColumn self-heal in the provider boot for existing DBs), whitelist both in getAllFields(), and wire them through RepositoryService create() insert, update() upsert, and the getBySlug COALESCE select so edit pre-fills. Verified create/read/update round-trip
