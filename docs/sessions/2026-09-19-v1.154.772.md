# v1.154.772 (2026-09-19)

fix(cron,nas-watchdog): CronRunTracker truncated output by byte, splitting 3-byte progress-bar glyphs (U+2591-2593) so utf8mb4 rejected the update with 1366, finished_at was never written and the missed-run detector raised false misses; now cut by character and mb_scrub'd (CH-000097, the column was already utf8mb4). supportsDistributedLocks() used a driver-name allowlist that omitted file although FileStore implements LockProvider, so onOneServer() was skipped and a warning logged on every schedule boot; now asks the store (CH-000096). NAS watchdog gains NAS_WATCHDOG_PATH so an instal whose storage_path is a local overlay upperdir probes the real NFS mount instead of reporting DOWN. New CronRunTrackerOutputTest, ahg-core 6/6.
