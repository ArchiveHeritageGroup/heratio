# v1.156.3 (2026-09-28)

fix(tests): clear AclService's cached identity between tests (heratio#1515). AclService keeps the signed-in user and their ACL groups in statics that outlive a test, so one case's
  actingAs admin was still the answer for every later case in the same process - tests asserting what a GUEST may see were quietly running as an administrator. ActorVisibilityTest caught it, a guest seeing draft and embargoed authority records, but only
  when something signed an admin in first, which is why it passed alone and failed in the full suite; StorageMovementTest in v1.156.0 was the trigger, not the defect. tests/TestCase now calls AclService::forgetUser() in setUp and tearDown, which is what
  that helper was written for and had no callers. Full suite 1487 tests, no failures.
