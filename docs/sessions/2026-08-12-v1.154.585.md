# v1.154.585 (2026-08-12)

fix(deploy): #1465 reconcile the IIIF templates with reality + stop install-cantaloupe destroying the host map. LIVE HAZARD FIXED, not just drift: bin/install-cantaloupe rendered delegates.rb unconditionally from the template with a SINGLE entry, so re-running it for one instance silently wiped INSTANCE_PATHS for every other vhost on the box - each would fall through to DEFAULT_PATH and 404 all of its images, surfacing to users as a JSON parse error rather than a missing file. One Cantaloupe serves every instance here, so installing instance B must not un-map instance A. It now MERGES: an existing delegates.rb is backed up, a host already present has its path updated in place, a new host is inserted after the INSTANCE_PATHS brace, and every other entry is left alone; only a genuinely absent file falls back to rendering the template. Verified against a copy of the real 11-host map - added a new host, updated an existing one, all others preserved, ruby -c still clean. NGINX SNIPPET TEMPLATE reconciled with the live config; they had drifted in BOTH directions and neither was correct. Taken from live: Host $http_host rather than $host ($host drops the port, so Cantaloupe builds a port-less info.json id, the viewer requests tiles from an origin the page CSP img-src rejects, and Mirador renders blank - the template would have reintroduced that on any non-443 instance), X-Forwarded-Port $server_port, the /iiif/3d/ Laravel passthrough, and the sub_filter backstop. Kept from the template, which live had lost: proxy_http_version, X-Real-IP/X-Forwarded-For, Cookie + Authorization forwarding for delegates.rb authorize(), connect/send/read timeouts, the full CORS method and header set, and proxy_cache_valid. The live snippet is now rendered from the reconciled template, so sasa gained back the timeouts and CORS headers it had been missing. Also tracked deploy/nginx/heratio-dev.conf and deploy/nginx/sasaarchive.theahg.co.za.conf, so all four vhosts are versioned instead of two (checked for secrets first - only Certbot cert PATHS, same as the already-tracked heratio.org.conf). Verified: nginx -t passes, sasa info.json still 200 with a clean port-less id, all five Laravel passthroughs still reach the app rather than Cantaloupe (auth 401 application/ld+json, discovery 200), IIIF still 200 on dev, prod and sasa, Unit 21/21
