# v1.154.463 (2026-08-03)

fix(display): image carousel now shows a collection's descendant images, not just direct children. The child-thumbnail query for the imageflow carousel used only direct children (usage_id 142), so a top-level collection whose direct children are image-less intermediate series (e.g. demonstration-collections: 7 image-less children, 68 thumbnails deeper) rendered an empty carousel. Walk the whole descendant subtree via the closure-backed HierarchyQueryService::descendantIds (fallback to direct children; IN() capped for huge trees; ordered for stable results)
