# v1.154.465 (2026-08-03)

fix(museum): show the child-image carousel on museum collection pages. MuseumController::show didn't compute childThumbnails, so the shared _digital-object-viewer partial's imageflow strip stayed hidden for museum collections whose images live below the first level. Now builds childThumbnails from the whole descendant subtree (closure-backed descendantIds, usage_id 142, capped + ordered) and passes them, matching the archival + DAM show fixes
