# v1.154.691 (2026-08-29)

chore(repo): remove stray absolute-path artefacts from the repository root, and rescue three research notes KM could not see. The root carried a directory literally named ' ' (a single space) and a file literally named '"', both tracked, plus a tracked usr/share/nginx/heratio/patch_routes.py. All three are the signature of a script writing to "$VAR/absolute/path" with an empty variable and a stray leading space, which created a directory named space and mirrored the whole absolute path beneath it. Surfaced by the workbench portfolio file scan, which listed ' ' and '"' as filenames. The real cost was hidden inside: docs/research/data-migration.md, ipsas-heritage-assets.md and rights-vocabularies-embargo-management.md existed ONLY under the stray path, so they were never in docs/ and the KM watcher has never indexed them - three research notes invisible since 14 June. Those are moved into docs/research/, taking it from 35 files to 38, and the watcher will pick them up. The six remaining stray copies are dropped: two were byte-identical to the canonical version and four are near-duplicate drafts of the same notes, differing only in revision and title casing, all committed together in a28c57022, so nothing is lost - both variants remain retrievable from that commit for anyone who wants the alternate drafts. Also drops composer.json.orig and close_audit_issues.py.orig, tracked patch leftovers of exactly the class that caused a real secret leak through bin/release's git add -A; both were checked and contain no credentials. stuff/ is untouched, being gitignored already.
