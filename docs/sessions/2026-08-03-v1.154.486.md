# v1.154.486 (2026-08-03)

fix(authority): #1433 - draft/embargoed authority records drop from ES-backed search. ElasticsearchService::globalSearch queried qubitactor with no publication/embargo filter (only autocomplete had it), so a draft or currently-embargoed actor could still surface in global search for an anonymous user; added the same should-arm (publicationStatusId absent OR =160) + must_not embargoUntil>now/d. Added ElasticsearchService::indexActor(id) - a best-effort single-doc reindex (never throws into the save; same doc shape/cultures as the bulk EsReindexCommand) - fired from ActorController store()/update() after setActorPublicationStatus, so a status/embargo change reflects in ES immediately without a full ahg:es-reindex. Keep-and-filter model, no editor bypass (matches the IO search()/autocomplete pattern; editors find drafts via SQL-backed browse). Regression test EsActorVisibilityTest (Http::fake body assertions). Per-instance deploy: run ahg:es-reindex --index=actor once to sync existing actor rows (the new hook only covers future saves).
