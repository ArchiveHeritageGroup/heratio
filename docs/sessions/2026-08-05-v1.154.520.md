# v1.154.520 (2026-08-05)

feat(#1457): linked digital objects get full viewer functionality (zoom/Mirador). Two parts. (1) Manifest quality: IiifCollectionService::loadObjectAndDigitalObjects now emits one canvas per MASTER object (whereNull parent_id) instead of one per digital_object row - reference/thumbnail derivatives carried the same object_id and produced noisy extra canvases (engelbrecht 10 -> 4 canvases: the real objects only). (2) Viewer: when a record has >1 object (primary master(s) + attachments), _digital-object-viewer passes the record multi-canvas IIIF manifest (/iiif-manifest/{slug}) to initIiifViewer; ahg-iiif-viewer.js showMirador() loads that remote manifest so Mirador shows ALL objects (primary + Recto/Verso) with deep zoom + a thumbnail navigator, instead of the inline single-image manifest. Single-object records pass empty and keep the inline path unchanged (no regression); Mirador-load failure shows an inline warning rather than crashing. Verified: manifest 10->4 canvases; multi-object record emits the manifest URL as initIiifViewer 5th arg; JS + views compile.
