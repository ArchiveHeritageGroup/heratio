# v1.154.591 (2026-08-13)

ExportController::csv now takes descendants from HierarchyQueryService::descendantIds (closure-backed, falls back to direct children when bounds are unusable), matching the v1.154.456 preservation fix. Verified: 31-node collection exports 31 records
