# v1.154.560 (2026-08-10)

feat(icip): #1448 - wire the Local Contexts Hub integration (was a stub). LocalContextsHubService now does real Hub work behind the enable flag: fetchProject() calls GET {hub}/api/v1/projects/{unique_id}/ via Laravel Http (X-Api-Key header when set, 10s timeout, 1 retry, 6h cache); syncProject()/syncAll() persist a project's applied TK/BC Labels + Notices into a self-healed icip_hub_project table; labelMetadata() prefers synced Hub data and FALLS BACK to the local icip_tk_label_type catalog (never blocks); query() searches synced labels. New scheduled command ahg:icip-hub-sync registered in CronSchedulerService DISABLED-by-default (managed-cron pattern). Config seam seeded in icip_config (hub_enabled=0, hub_url, project_ids; api_key already SecretCrypto-wrapped). Fully additive + guarded: with the module disabled or no credentials/table, every path behaves exactly as before (local catalog only). Verified: self-heal creates table+config, disabled command no-ops, cron entry is_enabled=false, labelMetadata falls back to local ('TK Attribution'), and a real Hub call for a bogus project degrades to ok=false without throwing. LIVE end-to-end sync still needs a registered Hub project + credentials (documented external blocker) - inert until an operator supplies them.
