# v1.154.464 (2026-08-03)

fix(dam): show the child-image carousel on DAM collection pages. The DAM show page includes the shared _digital-object-viewer partial but never passed childThumbnails, so its imageflow strip stayed hidden - a DAM collection like collection-ai showed no carousel of its child images. DamController::show now builds childThumbnails from the whole descendant subtree (closure-backed HierarchyQueryService::descendantIds, usage_id 142, capped + ordered) and passes them through, matching the archival show fix
