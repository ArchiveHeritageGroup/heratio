# v1.154.604 (2026-08-14)

fix(cron): ahg:authority-function-sync no longer hard-defaults to the atom database. --connection defaulted to 'atom', which only exists on an AtoM overlay install; on a Heratio-native instance the probe threw 'Access denied for user sasa to database atom' on every scheduled run. It now defaults to the instance discovery_db_connection setting, falling back to the application's own default connection, and the source probe is wrapped so an unreachable or forbidden source reports and exits 0 - there is nothing to sync, which is not a fault - instead of throwing before the existing no-relation-table guard could return
