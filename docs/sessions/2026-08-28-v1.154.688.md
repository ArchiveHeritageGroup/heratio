# v1.154.688 (2026-08-28)

fix(docker): stop shipping working passwords in the test stack - the example carried three live-looking defaults and docker/.env.docker was tracked as a copy of it, so any copy-paste deployment inherited credentials published in a public repo. No production credential was ever exposed: .env has never been committed in the entire history, no tracked file assigns a secret to a literal, and the docker values were verified by hash to differ from the live ones. The example now ships CHANGEME_ placeholders and docker/init.sh refuses to boot when any of DB_PASSWORD, DB_ROOT_PASSWORD or ADMIN_PASSWORD is unset or still a placeholder, rather than coming up reachable on passwords anyone can read - tested both directions, placeholder aborts with exit 1 and real values continue. Untracks docker/.env.docker, which the README already instructed people to create locally from the example. Also adds eight KM reference notes covering the recordkeeping crosswalk, Emerald submission requirements and current client and market work.
