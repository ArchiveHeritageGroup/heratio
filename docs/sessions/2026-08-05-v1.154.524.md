# v1.154.524 (2026-08-05)

fix(mail): queued email (password reset, notifications) now sends - DB SMTP config applied in the queue worker too. Root cause: password-reset (and other) mail is Mail::queue()d, but the operator SMTP settings (email_setting: Gmail smtp.gmail.com:587) were applied only per-web-request in LoginController::configureMailFromDatabase. The queue WORKER sends the mail in a separate process that never ran that, so it used the .env default (MAIL_MAILER=log / smtp 127.0.0.1:2525) and failed with 'Connection could not be established with host 127.0.0.1:2525' -> the email never arrived (2 failed_jobs were exactly the reset attempts). Fix: AppServiceProvider::boot() now applies the email_setting SMTP config globally (web + console + queue), cached 300s, .env fallback on error. Verified: console/worker context resolves smtp.gmail.com:587/tls, and a live Mail::raw test was accepted by Gmail. Requires a queue-worker restart to take effect.
