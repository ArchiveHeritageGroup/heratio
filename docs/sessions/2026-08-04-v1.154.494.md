# v1.154.494 (2026-08-04)

i18n(#1416): SA-language UI coverage batch 2 - isiZulu/isiXhosa/siSwati/Sepedi, run on the .76 RTX 3090 GPU (per the GPU-node policy, off the shared prod host). Same offline NLLB-200-distilled-600M pipeline as batch 1 (clean UI labels only, passthrough/garbage guarded, byte-identical PHP JSON format, flagged machine-translated in _meta.json for native-speaker review) but on CUDA - ~52,452 translations in ~2 minutes (25x the CPU rate). Coverage of the 17,922 codebase __() keys: zu 4.5->75.4%, xh 3.9->75.3%, ss 3.9->74.0%, nso 3.5->73.5%. With batch 1 (ts/tn/st ~73%), 7 of the 9 non-Afrikaans SA languages now sit at ~73-75% (from 1.4-4.5%). Tshivenda (ve) + isiNdebele (nr) remain excluded - the distilled 600M model returns English passthrough for them; they need a larger NLLB or human translation.
