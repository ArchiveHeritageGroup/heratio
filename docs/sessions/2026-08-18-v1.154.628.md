# v1.154.628 (2026-08-18)

fix(federation,cron): stop the nightly federation-vocab-sync failure, and give dev's facet cache a driver. FEDERATION - the single error logged overnight was sasa's 'Scheduled command [ahg:federation-vocab-sync] failed with exit code [1]' at 03:00. Two defects, both biting only where the federation_enabled setting row is ABSENT (sasa has no row; dev and heratio.org both have it set to 1). (1) VocabSyncCommand returned self::FAILURE when federation is off - a configuration choice reported as a runtime fault - so the scheduler recorded an ahg_error_log row every night. HarvestCommand was already fixed this way and its comment describes this exact symptom; VocabSync was missed. It now warns, points at Plugin Management, and returns SUCCESS. (2) The scheduler gate and the commands read the same setting with OPPOSITE defaults: FederationService::isEnabled() defaulted to '1' while both commands default to '0', so on an instance with no row the gate decided federation was ON and ran the command, which then reported it OFF - a guaranteed nightly failure. isEnabled() now defaults to '0', which also closes EnsureFederationEnabled by default: a feature that exchanges data with external peers should not enable itself by omission. No change where the row exists (verified on dev: isEnabled() still true, vocab-sync still exits 0). FACET CACHE - dev's facets were 66h stale because neither driver covers it: /etc/cron.d/ahg-facet-cache iterates 'for d in dam heratio' and runs the PROD codebase with a DB_DATABASE override, and the managed cron_schedule row needs Laravel's scheduler, which is deliberately disabled on dev. New versioned deploy/cron/heratio-dev-facet-cache runs DEV's OWN artisan hourly as www-data (same pattern as heratio-am-dev), installed to /etc/cron.d and registered in the check-config-drift manifest (15 compared, no drift). Sasa had the same gap - nothing owned its facet refresh - so its managed row is now enabled (DB-only; prod stays off because the cron file owns it there). 231 Feature tests pass
