# v1.154.719 (2026-09-04)

fix(privacy): a redacted TIFF is now something a browser can actually display. The redaction path cannot go through Cantaloupe - Cantaloupe tiles the ORIGINAL file, so leaving the IIIF image service in a redacted record's manifest lets a viewer deep-zoom straight past the redaction - and dropping the service also drops Cantaloupe's transcode. That is what made this matter: RedactionRenderService kept the master's extension for the derivative and PrivacyController served it under the master's mime type, so a redacted TIFF was burnt in as TIFF and sent as image/tiff. No browser renders that, so Mirador showed nothing at all. Fail-safe, but only by accident, and it means v1.154.715 did not really replace the hide-Mirador behaviour for image masters, it only made the failure quieter - on exactly the format the deep-zoom viewers exist for. It went unnoticed because the only redacted record on dev is a PDF, and PDFs were always served correctly. Now: derivativeExtension() writes jpg for any image format a browser will not render, keeps jpg, jpeg, png, gif and webp as they are, and never touches a PDF, where the file type wins over the extension. mimeForPath() reads the content type off the DERIVATIVE, and returns application/octet-stream for anything it cannot name rather than a type the browser would act on. The Python redactor needed no change - it already selects its output format from the extension and normalises to RGB - so the whole defect was PHP choosing the wrong extension and then misdescribing it. STALE CACHE WOULD HAVE DEFEATED THE FIX: regions_hash covers the regions and not the output format, so a row written before today points at a valid .tiff derivative that still exists and would have been served forever. A cache hit now also checks the stored extension is the one that would be written today and re-renders when it is not, so it heals itself with no manual purge. Verified through the real redactor rather than reasoned about: a TIFF master produces a 600x400 JPEG, black inside the region and untouched outside, and the live redacted record still returns 200 application/pdf byte for byte. 22 tests on the two pure statics, including that every extension written has a content type that can name it. 1073 Package tests pass, up from 1058, and 286 Feature tests pass.
