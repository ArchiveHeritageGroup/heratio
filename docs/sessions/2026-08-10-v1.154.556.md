# v1.154.556 (2026-08-10)

feat(viewer): OpenSeadragon deep-zoom for JPEG/PNG via Cantaloupe (not just TIFF/JP2). ahg-iiif-viewer.js needsIiif now matches jpe?g|png as well as tiff?|jp2|jpx, so ordinary raster derivatives get a tiled IIIF pyramid instead of a flat single-resolution image. Cantaloupe is healthy again (info.json + tiles 200 direct and via the public /iiif/2,/iiif/3 proxy), so the #1457-era 'plain JPEG to dodge Cantaloupe' workaround is no longer needed. Safety: (a) webp/gif/svg/avif stay on the plain path (Cantaloupe 501s on webp); (b) new OSD open-failed handler falls back once to the plain image if any tile source can't be opened - zero regression; (c) redacted assets already resolve to a redaction-controller route (not a raw /uploads path), so Cantaloupe can't serve them -> they fall back to the plain redacted image, i.e. no redaction bypass. Added a filemtime cache-bust on the viewer <script> so the change reaches cached browsers. Verified: getUrl returns the raw /uploads path whose _SL_ Cantaloupe identifier returns 200; node --check clean; blade compiles.
