# v1.154.504 (2026-08-04)

fix(marketplace): listing-image upload failed with 'Please select an image to upload' - field-name mismatch. The seller-listing-images form posts name=image_file + name=caption, but sellerListingImagesPost() checked $request->hasFile('listing_image') and input('image_caption') (and validated 'listing_image'/'image_caption'), so the uploaded file was never found and every upload flashed the error. Aligned the controller to the form (image_file / caption). PHP FPM upload limits are 2G, so size was never the cause. Reported by Stefan on heratio.org/marketplace/seller/listing-images.
