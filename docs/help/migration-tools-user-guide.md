# Migration Tools

## User Guide

**Last Updated:** 2026-10-26

Heratio's migration tool is the **Data Migration** wizard (**Admin > Data Migration**). It imports the rows of a CSV or Excel file with a header row, mapped column by column, as archival descriptions, accessions, authority records or repositories. Imports run in the background and are followed on the Jobs page.

Any system that can export a spreadsheet can be migrated this way. The wizard has no presets for particular products, and it does not read XML, Preservica OPEX or PAX packages, or digital object files. Library, museum, gallery and digital-asset records, and imports with digital objects, go through the **Ingest** wizard (`/ingest`).

The full guide, with the field list, import types and troubleshooting, is [Data Migration - User Guide](/help/article/data-migration-user-guide).
