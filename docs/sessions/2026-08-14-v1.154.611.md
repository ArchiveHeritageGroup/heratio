# v1.154.611 (2026-08-14)

feat(audit): close the information_object diff gap - the five per-standard editors now record before/after. InformationObjectService and its controller were already instrumented, but a description saved through the dynamic per-standard form (#1425) goes to that standard's own persist() instead, and none of DACS, Dublin Core, MODS, RAD or RiC captured anything - so 33 of 51 dev description updates recorded a path and nothing else. Each persist() now snapshots before its writes and captures after, reusing InformationObjectService::auditSnapshot (already public static) so every standard diffs the same field set rather than each inventing its own idea of what counts as a change; guarded with class_exists so a standard package installed without io-manage degrades to no capture rather than fataling. The accession gap turned out NOT to be a gap: AccessionController already calls the instrumented service, and captureEdit deliberately records nothing when diffFields finds no change, so those path-only rows are edit-page submits that changed nothing. Verified by experiment - two real accession edits produced two diff rows and a no-op submit produced none - and both probe records were restored to their original values
