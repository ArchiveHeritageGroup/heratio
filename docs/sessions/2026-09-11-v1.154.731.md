# v1.154.731 (2026-09-11)

fix(i18n): the Translation lint workflow is green again - both jobs, at their existing thresholds. It has been red since at least 8 Sep across v1.154.726, 728 and 729, so this is accumulated debt rather than a regression from any recent release; heratio-be confirmed its docs-only 729 did not introduce it and routed it here. LOCALE KEY EXTRACTION: 591 keys used via __() in the codebase were absent from lang/en.json against a threshold of 100, so those strings rendered as English only because __() falls back to the key - no translator could reach them, and no locale could ever cover them. Heaviest modules were ahg-archaeology 96, ahg-heritage-manage 92, ahg-information-object-manage 62, ahg-harris-matrix 34. Extracted, taking the file from 18,819 to 19,410 entries and coverage from 96.7% to 100%. HARDCODED UI STRING SCAN: 90 candidates in 31 files against a threshold of 30. These are strings a translator cannot reach at all, because they are not marked for translation in the first place. Wrapped 85 of them in __() across 26 files, driven by the lint's OWN candidate list rather than a broad sweep, so nothing outside what it flagged was touched. Only plain literal text was rewritten - anything containing Blade, PHP, markup or an existing __() call was skipped by construction. That leaves 5 candidates, all correctly left alone and worth naming so nobody 'fixes' them later: one is the Blade directive @yield('record-title'), two are example URLs in placeholders which must not be translated, and two are already inside __() and are false positives the lint reports because the call sits in a PHP string concatenation. Wrapping introduced 38 new keys, extracted in turn, so the file settles at 19,448 and both gates pass together rather than one breaking the other. Verified rather than assumed: lint exits 0 at threshold 30, extract exits 0 at threshold 100, the malformed-locale guard exits 0, every Blade template compiles, __() resolves the wrapped strings to their English text rather than to a key, and the site still serves - 200 on the homepage, GLAM browse and a record page, with nothing new in the error log. 1126 Package tests pass and 286 Feature tests pass. The threshold was not raised; the debt was paid.
