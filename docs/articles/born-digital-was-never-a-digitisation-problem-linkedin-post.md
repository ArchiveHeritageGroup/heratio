# LinkedIn post - Born-Digital Was Never a Digitisation Problem

An archive is handed a retiring executive's hard drive: twelve years of email, board papers, a finance database, CAD files for a building that no longer exists.

Someone asks when to scan it.

You don't. There is nothing to scan. The record was digital from birth, and that one fact quietly breaks most digitisation thinking.

A scanned minute book has a fallback: lose the file, the book is still on the shelf. An email has none. The file is the original. Lose the bytes and there is no re-scan.

So born-digital is not a capture problem. There is no resolution to choose, no colour target. It is custody:

- reading the drive without altering it (write-blocking, forensic imaging)
- proving with fixity that nothing has changed since accession
- knowing what each file actually is before you trust it
- keeping it readable as formats quietly die

The tools for all of it are open, proven and free: OAIS, PREMIS, DROID, Siegfried, BagIt, BitCurator.

The hard part was never the technology. It is deciding to do the work before the drive in the drawer becomes unreadable.
