# v1.154.497 (2026-08-04)

feat(icip): #1427 - graded-access audit log + workflow-state consultation routing. Adds the icip_access_log table (self-installed in AhgIcipServiceProvider::ensureGovernanceTables, append-only, like ocap_event) and logs every allow/deny decision on an ICIP-restricted object from IcipController::checkAccess() with the decision, restriction types, acting user and reason (#1427 item 4 - the account a source community can ask for). Routes the workflow-state protocols elder_approval_required + under_consultation to a non-blocking requires_consultation result (linking the icip_consultation record) instead of ignoring them or blanket-denying staff (#1427 item 2). The 5 unambiguous hard-block types (community_permission_required/initiated_only/repatriation_pending + the date-windowed seasonal/mourning_period) are unchanged. Verified: deny + allow_consultation decisions both audit-logged with reason+user. STILL DEFERRED pending a product decision (#1427 items 1+3): the gender_restricted_*/custom types need a community-supplied user-attribute model, and the per-type fail-direction must be decided explicitly. Table auto-creates on first boot after deploy.
