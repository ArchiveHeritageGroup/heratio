# v1.154.698 (2026-08-30)

feat(api): descriptions can carry dates - ISAD(G) 3.1.3 was unwritable through the API - #1496. Dates came OUT of the API fully formed and could not go IN: POST and PUT validated 22 fields and none of them was a date, and the events endpoints were read-only, so a client could see a date the API gave it no way to set. Create and update now accept a dates array. BOTH HALVES ARE KEPT, deliberately: start_date and end_date are normalised and sortable, date_display preserves the expression the archivist actually wrote - 'circa 1890s', 'n.d.', '1890-1899?'. Normalised alone loses the uncertainty a person recorded; text alone loses the ability to sort or range-query; neither is sufficient. Type resolves through the Event Types vocabulary rather than accepting a free string, scoped to that taxonomy because several taxonomies contain a term called Publication and matching on name alone would silently mis-type the date. An unknown type is REJECTED with a 422 listing the valid types rather than stored as NULL - a date that silently loses its type is worse than a refused request, because the record looks complete and the caller never learns it was dropped. Writes go through a new AhgCore\\Support\\EventRow helper rather than inserting into event directly: event is a class-table-inheritance child of object, so its id must be an object row with class_name QubitEvent, and an invented id produces a row that violates the inheritance and is invisible to anything joining through object. On update, dates are replaced wholesale when the key is present and left untouched when it is absent, so a PUT that does not mention dates cannot silently delete them. Driven end to end against the running API with a temporary write-scoped key: create with two dates returns 201 and both round-trip through GET with types Creation and Publication and their display expressions intact; an unknown type returns 422; PUT replaces; PUT without the key leaves them alone. Raised by the bookings session, which needs to push a completed conference in as a properly dated description rather than a paragraph that happens to mention July. 246 Feature tests pass.
