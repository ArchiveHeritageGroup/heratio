# v1.154.783 (2026-09-23)

fix(theme): WhatsApp bubble had no logo, and the voice mic sat on top of it on phones. The bubble used <i class='bi bi-whatsapp'>, but the theme serves Font Awesome and the Bootstrap Icons stylesheet that defines bi-whatsapp is loaded on two pages only, so it rendered as an empty green circle; the mark is now inline SVG extracted from the shipped bootstrap-icons.woff (U+F618), with no icon-font dependency. The mic moves from 80px to 92px so it clears the bubble by 16px instead of 4px, and on phones from 70px - where it OVERLAPPED the bubble by 6px, mic on top - to 92px, with the toast container and the bubble's right edge adjusted to match. The text channel stays the lowest and easiest to reach for visitors who cannot use the mic. WhatsAppBubbleTest now asserts the inline SVG is present and bi-whatsapp is gone; 8/8 pass.
