# v1.154.508 (2026-08-04)

feat(#1454): GRAP heritage-asset accounting moved to Heritage Accounting + full field parity. The thin /admin/spectrum/grap-dashboard (Museum procedures, empty spectrum_grap_data, boolean tiles only) now redirects to the rich Heritage Accounting record: with a slug -> /heritage/accounting/by-object/{id}, without -> the accounting dashboard (guarded by Route::has; ?export= still hits the legacy path). Implemented the stubbed HeritageAccountingController::view() + viewByObject() to load the full heritage_asset row (63 cols) joined to class/standard + its information object; new view.blade.php groups every GRAP 103 field into 11 lifecycle sections (recognition, measurement, valuation, depreciation, impairment, derecognition, restrictions, insurance, location/condition, audit) with money/date formatting + headline figures. Objects with no accounting record redirect to the pre-linked Add form. Verified: view(7) renders 11 sections; slug + no-slug + by-object redirects resolve
