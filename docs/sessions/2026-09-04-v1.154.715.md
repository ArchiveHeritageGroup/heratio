# v1.154.715 (2026-09-04)

fix(tests,privacy): every package's tests now run in CI, the three failures they were hiding are fixed, and Mirador is served redacted pixels instead of being hidden. CI COVERAGE: the Package suite was a hand-maintained list of 13 directories, so 26 packages with real tests ran nowhere - a list that must be updated by hand to keep coverage is a list that silently loses it. It now globs packages/*/tests with the two exclusions All already carries. Package goes from 398 tests to 1044, and the job from about a minute to twelve and a half. THE THREE FAILURES were none of them product defects; all three were tests asserting against a database that is not empty. SushiServerTest passed alone and failed only in All: four ahg-library tests boot a bare container and point the facades at it, but setFacadeApplication does not clear the facade cache, so a LogManager resolved earlier by a Laravel-booting test answered Log::warning and looked up config on an application no longer bound. Cleared at both ends in the package base class, since ordering between test classes is not ours to rely on. SpectrumComplianceTest: line 182 is the second assertion and spawned was 1 throughout. heratio_test seeds all 21 Spectrum workflows, the service fires the chain into the lowest-id active workflow for the target procedure, and every workflow the test creates has a higher id, so the task landed in the seeded workflow and the count on the test's own never moved. The test deactivates the seeded rows first; its sibling was passing for the wrong reason and now asserts the first spawn as well. SeedSpectrumCommandTest asserted loans_in was absent from ahg_workflow entirely, which cannot hold against that same seed - the only flag was correct all along. It now stamps every Spectrum workflow with a stale updated_at, runs with overwrite, and asserts exactly the named procedures moved, which is the only thing the flag can promise on a populated database. MIRADOR builds its own OpenSeadragon from an element rather than an id, so it never enters OpenSeadragon's registry and the redaction shim cannot reach it to place overlays; the only route left is React internals, which is not worth shipping. v1.154.714 hid it. It is now handed the server-side burnt-in derivative instead, which is the stronger answer regardless: an overlay covers the pixels on screen while the tiles underneath stay downloadable. The image service is dropped along with it, and that is the part that matters - Cantaloupe tiles the ORIGINAL file, so leaving the service in the manifest would let Mirador deep-zoom straight past the redaction. Verified in a browser: two requests to the redacted asset, no Cantaloupe tile request, Mirador visible when a derivative is available and hidden when it is not. The image redactor was checked directly, black inside the region and white outside. Multi-object records keep the fail-closed hide, because that endpoint serves one master per record. 1044 Package, 286 Feature, and the All suite passes end to end for the first time - 1356 tests, 4014 assertions, no failures.
