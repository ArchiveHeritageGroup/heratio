# v1.154.470 (2026-08-03)

feat(heritage): inline recognition-status dropdown on the accounting browse grid. Each asset row's Status is now a select (Pending / Recognised / Not Recognised) that updates the record via AJAX (POST /heritage/accounting/{id}/status, acl:update, CSRF, whitelisted values) and reflects in the grid without a reload - recognising also stamps recognition_date shown in the Recognised column; reverts + alerts on failure. Read-only viewers still see plain text
