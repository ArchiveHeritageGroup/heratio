# Bigibila Nations - AHG development + sovereign-hosting proposal (Australia)

**Summary.** The AHG has drafted a development and Australian sovereign-hosting partnership proposal for **Bigibila** (an Indigenous-led governance/data/IP consultancy founded by **Liana Pitt**; entities: Bigibila Consultancy Firm and Bigibila IP Holdings Pty Ltd t/a Bigibila Systems), in response to Liana Pitt's *Bigibila Governance, Archaeology and First Nations Survival Report* (v1.0, Aug 2026). The opportunity is to become the **build + sovereign-hosting partner** for **"Bigibila Nations"** - the federated, consent-based Indigenous-data-sovereignty platform Bigibila has already designed. This is **not a digitisation project**. Cultural authority leads; technology follows. Emailed to Johan 2026-08-22; a live proposal (cold-ish, AHG not previously named). Deliverable: `stuff/Bigibila-Nations-Development-Proposal.{md,docx,pdf}`.

## What Bigibila is (business level only)

Indigenous-led consultancy + IP holding company + planned software arm, not a Nation or community. Liana Pitt's family research responsibilities: Gamilaraay, Gomeroi, Yuwaalaraay (relational river Country, north-western NSW). The platform is meant to serve **many** distinct First Nations "Nation by Nation," each separately governed - **no pan-Aboriginal defaults**. The report's method is "Governance Archaeology" (excavating institutions, not physical digs); its through-line is governance + Indigenous data sovereignty, with heritage/native-title/records as use-cases.

## The proposal posture (important)

- **Governance/consent/evidence infrastructure, NOT digitisation or discovery.** Much material is deliberately kept OUT (a "do not digitise" Lore Gate outcome). Pitch value = verifiable, federated, consent-and-authority governance with minimum-disclosure interoperability.
- **Lore-Led:** cultural authority leads; technical systems record and enforce. "Technical access is not cultural permission." Authority is validated separately from login (RBAC alone is insufficient).
- **IP-protective / humble:** AHG builds and hosts only; Bigibila keeps all IP/method/architecture/terminology; Nation data is Nation-owned/jointly governed, held by AHG as a processor in Australia; no acquisition, sublicence, commercialisation or AI-training on Bigibila IP or Nation data; benefit-sharing; data return/deletion on exit; survival of cultural conditions after contract.
- **Australian sovereign hosting mandatory** (data residency, per-Nation isolation, keys, exit/return - the report's "Burrow Sovereign Cloud").
- **Authority-before-build:** no engineering, and no build price, before Phase 0 approves the authority and rights settings.

## Platform mapping (Heratio -> Bigibila Nations)

Strong fit: ODRL rights-policy engine + enforcement middleware -> Lore Gate (five outcomes: Proceed / Proceed with conditions / Pause / Decline / Do not digitise); records provenance/relations/status/audit -> authority + chain of custody; records-management (file plan, retention) -> cultural classification + do-not-digitise; multi-instance isolation + REST API -> Nations Integration Platform (minimum-disclosure evidence packages, never raw registers); gateway-only AI posture -> AI gate (no AI on cultural material without purpose-specific consent, no training on restricted knowledge). New build: a distinct Cultural Authority validation layer; FPIC consent lifecycle; per-Nation configurability (honest tension: AHG's central-taxonomy/dropdown model must become per-Nation - flagged in the proposal).

## Delivery + costing (AUD excl GST, AACE Class 5/4)

Phases mirror the report: Phase 0 Protect -> 1 Prove (single-Nation governed pilot: MVP + Lore Gate + sovereign hosting) -> 2 Assure (independent legal/cyber/privacy/ICIP audit) -> 3 Connect -> 4 Scale -> 5 Reform.

- Phase 0 (discovery + co-design, firm): AUD 70,000.
- Phase 1 pilot: point AUD 486,200, range AUD 340k - 730k; 309 person-days, effort itemised per function.
- Recurring per governed environment: ~AUD 240,000/yr (190k - 300k).
- Later phases 2-5: indicative order-of-magnitude, phase-gated. Rate card reflects AHG blended international delivery (SA engineering + Australian-facing governance/hosting).

## Cultural sensitivities (must hold in any future work)
