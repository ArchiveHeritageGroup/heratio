# v1.154.578 (2026-08-11)

chore(rights): #1464 drop 8 dead rights tables + retire the duplicate Creative Commons vocabulary. DEAD TABLES: donor_agreement_right, donor_agreement_rights (singular AND plural, both dead), donor_rights_application_log, rights_derivative_log, rights_derivative_rule, extended_rights_batch_log, heritage_embargo, embargo_i18n - zero rows on every instance and no code anywhere reads or writes them; the only references are the CREATE TABLE statements that produced them. DUPLICATE CC VOCABULARY: creative_commons_license (+_i18n) held the same eight licences as rights_cc_license with identical ids (1=CC0-1.0 through 8=PDM-1.0) and the same meanings under renamed columns (allows_adaptation/allows_derivatives, requires_sharealike/requires_share_alike). rights_cc_license wins because it is what extended_rights.creative_commons_license_id actually resolves against and what ExtendedRightsService and RightsHolderService already join. Its only other consumer, ExtendedRightsController, is repointed - no data remapping needed since the ids match, though the i18n join key differs (rights_cc_license_i18n is keyed by id, creative_commons_license_i18n used a creative_commons_license_id column). The views only consume code/description/id/name/uri, all present on the survivor, so the renamed boolean columns are irrelevant. MIGRATION 2026_08_11_160000 is guarded: a dead table is dropped ONLY if empty, and logs a warning and keeps it otherwise - losing data to a cleanup migration would be far worse than leaving a stale table; the two CC tables are dropped knowingly as superseded, and only once rights_cc_license is confirmed present so a partial install cannot end up with neither. No down(): recreating empty tables is not a restore, and pre-drop mysqldumps of all three instances were taken instead. NOT touched: agreement_rights_vocabulary has 25 rows and no code references - data with nothing reading it is a question to answer, not something to delete on a cleanup pass. Also left: the three parallel rights-record stores and three embargo tables, which are design decisions (rights alone is referenced by 24 packages) and stay open on #1464. Rights/licence/embargo tables: 45 -> 38. Verified: /admin/rights/creative-commons and /admin/rights/statements render all 8 licences with their names via the repointed i18n join, controller returns 8, /egyptian-boat still shows CC0 1.0 Universal, Unit 21/21 and Feature 231 green
