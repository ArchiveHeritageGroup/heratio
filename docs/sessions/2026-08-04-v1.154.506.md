# v1.154.506 (2026-08-04)

fix(finding-aid): download filename = the collection/description title, not finding-aid-{id}.ext. FindingAidController::download() now passes the sanitised information_object title as the response()->download() name (fallback: slug, then the internal name), keeping the file's actual extension. So downloading the Engelbrecht Family Bible finding aid saves as 'Engelbrecht Family Bible.pdf' instead of 'finding-aid-837.pdf'. Verified via Content-Disposition. The stored file on disk keeps its internal finding-aid-{id} name (unchanged).
